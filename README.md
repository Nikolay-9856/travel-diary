# «Дневник путешествий» (кейс-задача № 5)

Python/Flask + SQLite + Leaflet (OpenStreetMap). Библиотека Leaflet 1.9.4 (BSD-2) лежит в `static/vendor`.

## Возможности
- регистрация и вход пользователя;
- запись путешествия: название, место, даты, рассказ;
- **местоположение с привязкой к геопозиции** — клик по карте или кнопка «Моё местоположение» (Geolocation API браузера);
- **изображения мест** — до 8 фото на запись (jpg, png, webp, gif), файлы сохраняются под случайными именами;
- **стоимость путешествия** с выбором валюты;
- **оценки** удобства передвижения, безопасности, населённости и растительности (1–5);
- просмотр путешествий других пользователей: общая карта с маркерами, поиск по месту, сортировка по дате, стоимости, средней оценке;
- личные записи, которые видит только автор; редактирование и удаление своих записей.

## Запуск
```bash
pip install -r requirements.txt
python seed.py        # необязательно: демо-пользователи masha / petya, пароль secret1
python app.py         # http://127.0.0.1:5002
pytest -q
```
Карте нужен доступ в интернет для загрузки тайлов OpenStreetMap; без него приложение работает, но подложка карты пустая.
Геолокация в браузере работает на `localhost` или по HTTPS.
